# 🛍️ FashionGPT & VirgilAblohGPT: AI-Powered Fashion Companion

Welcome to **FashionGPT**, an AI-driven fashion recommendation system, and **VirgilAblohGPT**, a conversational Hypebeast chatbot assistant! 🎭✨ This project is designed to revolutionize the way users explore fashion, combining **cutting-edge deep learning** with **AI-powered conversations** to create a seamless, personalized styling experience.

---

## 🚀 Overview

### **FashionGPT: Your AI Stylist**

FashionGPT uses **deep learning and computer vision** to analyze images and recommend similar fashion products. Whether you’re searching for streetwear, high fashion, or vintage pieces, FashionGPT helps you discover the perfect match.

### **VirgilAblohGPT: The Hypebeast Chatbot**

Inspired by the legendary **Virgil Abloh**, this chatbot, powered by **ChatGLM-6b**, provides insights into the latest fashion trends, styling tips, and industry knowledge. Engage in fashion discussions, get advice, and stay ahead of the curve!

---

## 🔍 How It Works

### **FashionGPT (Image-Based Recommendations)**

1️⃣ **Upload an Image** – Select an outfit or fashion piece you like.\
2️⃣ **Feature Extraction** – The system uses **ResNet50** to analyze visual patterns.\
3️⃣ **Similarity Search** – Nearest Neighbors algorithm finds visually similar items from a curated product database.\
4️⃣ **Personalized Recommendations** – Get top-matching products with details, colors, and style suggestions.

### **VirgilAblohGPT (AI Fashion Chatbot)**

💬 Engage with a smart chatbot that can:\
✅ Discuss fashion trends (Streetwear, Vintage, High Fashion, etc.)\
✅ Provide styling advice & outfit recommendations\
✅ Guide you on sustainable fashion choices\
✅ Offer AI-powered insights on industry shifts

## 🎯 Key Features

### **FashionGPT:**

✔️ **State-of-the-Art Deep Learning** – Uses **ResNet50** for advanced feature extraction.\
✔️ **Accurate Visual Recommendations** – Finds similar items from an extensive fashion dataset.\
✔️ **Interactive UI** – Compare original vs. recommended products easily.\
✔️ **Customizable Experience** – Adjust the number of recommendations and refine search results.\
✔️ **Diverse Fashion Categories** – Supports streetwear, luxury, casual, and more.

### **VirgilAblohGPT:**

✔️ **AI-Powered Fashion Assistant** – Built on **ChatGLM-6b** for in-depth fashion discussions.\
✔️ **Trend Insights** – Covers fashion weeks, celebrity styles, and seasonal trends.\
✔️ **Personalized Styling Suggestions** – Adapts responses based on user queries.\
✔️ **Multi-Topic Expertise** – Can discuss fashion sustainability, color theory, and cultural trends.

## 🛠️ Tech Stack

- **Deep Learning:** ResNet50, Nearest Neighbors Algorithm
- **NLP:** ChatGLM-6b for conversational AI
- **Backend:** Python, Flask/FastAPI
- **Frontend:** Streamlit (for interactive UI)
- **Database:** Fashion product dataset (custom-curated)

## 🏗️ Installation & Setup

### **1️⃣ Clone the Repository**

```bash
git clone https://github.com/Arshi81099/FashionGPT-AI-Powered-Fashion-Companion/.git  
cd FashionGPT  
```

### **2️⃣ Install Dependencies**

```bash
pip install -r requirements.txt  
```

### **3️⃣ Run the Application**

```bash
python app.py  
```

The app will be available at [**http://localhost:5000/**](http://localhost:5000/)
